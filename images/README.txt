🌸 IMAGE GUIDE — LESHINE EXPERIENCE
=====================================

Place your photos in THIS folder (/images/).
Then open index.html and find the 🖼️ EDIT comments.
Uncomment the <img> tag and set your filename.

RECOMMENDED SIZES (portrait phone):
  - All images: 800 x 1200 px (portrait ratio 2:3)
  - JPG format works best for photos

SCENES:
  1. opening-bg.jpg   → Opening splash background (optional, soft/blurry is great)
  2. cozy-room.jpg    → Slide 1: cozy indoor room, warm lighting
  3. hydrangea.jpg    → Slide 2: hydrangea flowers, garden scene
  4. forest.jpg       → Slide 3: forest, hummingbirds, nature

TIPS:
  - Darker images work best (the emoji floaters sit on top)
  - Center the main subject — edges get cropped on small screens
  - You can use free images from: unsplash.com or pexels.com
    (search "cozy room", "hydrangea", "hummingbird forest")

If you leave the <img> tags commented out, 
beautiful gradient backgrounds will show instead. ✓
